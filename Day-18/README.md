## LeetCode 34 – Find First and Last Position of Element in Sorted Array

Today I practiced Binary Search by finding the first and last occurrence of a target element in a sorted array.

### Problem

Given a sorted array `nums` and a target value, return the starting and ending positions of the target.

If the target is not present, return `[-1, -1]`.

nums = [5,7,7,8,8,10]
