# Day 7

## Problems Solved

### 1. Best Time to Buy and Sell Stock (#121)
- Difficulty: Easy
- Concepts: Arrays, Greedy
- Approach: Keep track of the minimum stock price seen so far and calculate the maximum possible profit.
- Time Complexity: O(n)
- Space Complexity: O(1)
- Status: ✅ Accepted

### 2. Maximum Subarray (#53)
- Difficulty: Medium
- Concepts: Arrays, Dynamic Programming, Kadane's Algorithm
- Approach: Use Kadane's Algorithm to find the maximum sum of a contiguous subarray in a single traversal.
- Time Complexity: O(n)
- Space Complexity: O(1)
- Status: ✅ Accepted
