# Day 09

## Problems Solved

1. LeetCode 73 - Set Matrix Zeroes
   - Difficulty: Medium
   - Approach: First Row & First Column Markers
   - Time: O(m × n)
   - Space: O(1)

2. LeetCode 128 - Longest Consecutive Sequence
   - Difficulty: Medium
   - Approach: HashSet
   - Time: O(n)
   - Space: O(n)

Today I learned:
- Using matrix itself as a marker array.
- Solving sequence problems efficiently using HashSet.
