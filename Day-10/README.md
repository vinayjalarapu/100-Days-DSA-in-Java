# Day 10

## Problems Solved

### 1. LeetCode 48 - Rotate Image
- Difficulty: Medium
- Approach: Transpose + Reverse
- Time Complexity: O(n²)
- Space Complexity: O(1)

### 2. LeetCode 54 - Spiral Matrix
- Difficulty: Medium
- Approach: Four Boundaries (Top, Bottom, Left, Right)
- Time Complexity: O(m × n)
- Space Complexity: O(1) (excluding output list)

## Key Learnings
- Matrix Transposition
- In-place Matrix Rotation
- Spiral Traversal
- Boundary-based Matrix Problems
