## 🚀 Day 28 – 100 Days DSA Challenge

### 🔹 LeetCode 8 – String to Integer (atoi)

**Difficulty:** Medium  
**Language:** Java  
**Topic:** Strings

### 📝 Problem
Implement the `myAtoi(String s)` function to convert a string into a 32-bit signed integer.

### 💡 Approach
- Ignore leading whitespaces.
- Check for `+` or `-` sign.
- Convert consecutive digits into an integer.
- Stop when a non-digit character is found.
- Handle integer overflow and return `Integer.MAX_VALUE` or `Integer.MIN_VALUE`.

### ⏱️ Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

### 📚 Key Learning
This problem helped me understand **string traversal, character-to-integer conversion, sign handling, and overflow conditions**.
