### 1. LeetCode 560 - Subarray Sum Equals K
- **Difficulty:** Medium
- **Approach:** Prefix Sum + HashMap
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)

**Key Learnings**
- Prefix Sum technique
- HashMap for storing prefix sum frequencies
- Optimizing subarray sum problems from O(n²) to O(n)

### 2. LeetCode 2996 - Smallest Missing Integer Greater Than Sequential Prefix Sum
- **Difficulty:** Easy
- **Approach:** HashSet + Sequential Prefix Traversal
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)

**Key Learnings**

- Sequential prefix traversal
- Finding the smallest missing integer efficiently
